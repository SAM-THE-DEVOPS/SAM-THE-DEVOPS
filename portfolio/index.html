Local DevOps Command Center (devctl)

          Source
        

        
A Python CLI that centralizes local Linux system diagnostics and health checks into one command surface — CPU, memory, disk, process, network, port, service and log inspection, without hunting through five different tools.

        
    
          
  • Unified interface over common system + DevOps operations: environment inspection, service management, operational status checks

  • Modular architecture so individual checks stay reusable, testable and easy to extend

Multi-threaded File Search Engine

          Source
        

        
A recursive Python file-search engine that walks directories concurrently instead of one at a time, with filtering by filename, regex, content, size and extension.
